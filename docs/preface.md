# 前言

## 为什么从计算机视觉走向具身智能

计算机视觉长期关注识别、检测、分割和重建。具身系统仍然使用这些能力，但评价标准发生了根本变化：模型的输出会进入动作，动作改变环境，环境再产生新的观测。错误不再停留在一张图片上，而会改变系统之后看见什么、能够做什么以及是否还能恢复。

世界模型位于这条变化的中心。它既可能是一种时序表征，也可能预测动作条件未来、为规划器提供候选评估、为策略生成想象数据，甚至充当代理仿真器。不同用途需要不同接口和证据。“能够生成未来”不等于“能够支持决策”，“能够输出动作”也不等于“动作已经 grounding 到具体本体”。

本书希望提供的不是某个模型的复现手册，而是一套经得住模型更替的判断框架。

## 本书怎样组织知识

全书围绕一条逐步增加语义的链展开：

```text
观测 -> 任务相关状态 -> 动作条件预测 -> 候选决策
     -> 闭环反馈 -> 评测证据 -> 部署与安全边界
```

前四章建立观测、状态、动作、数据和实验协议；第 5-9 章讨论生成式基础、RSSM、规划、想象学习与世界模型评测；第 10-12 章讨论预测表征和可行动空间；第 13-18 章进入模仿学习、生成式动作、VLA、数据规模化及世界模型与策略融合；第 19-21 章处理仿真、评测、实时性和安全；第 22 章把全书收束为一条可审计的研究方法。

## 三条写作原则

### 概念先于模型名称

论文和开源项目用于说明一种方法怎样实现，而不是决定章节结构。快速变化的版本进入研究雷达，稳定的定义、接口、反例和证据边界留在正文。

### 闭环先于开环分数

离线动作误差、视频质量和表征 probe 都有价值，但它们不能自动替代策略在自身诱导分布上的表现。书中始终追问：动作怎样改变下一状态，策略会不会利用模型错误，失败后是否能够恢复。

### 主张强度服从证据

本书区分可定位资产、可执行程序、可重复结果、独立验证和真实部署。教学反例只证明某种逻辑可能发生；仿真结果只支持对应环境和协议；真实机器人或车辆结论必须有相应目标环境证据。

## 怎样阅读公式和反例

公式用于澄清对象和依赖关系，不要求读者完成大段推导。第一次阅读时，应优先确认每个变量代表什么、条件分布以什么为条件、时间索引属于生成过程还是物理过程，以及损失在哪个数据分布上计算。

书中的微型反例不是性能实验。它们通常刻意构造两个看似相同、但在闭环后果上不同的系统，用来暴露平均值、覆盖率、相关性或成功率遗漏了什么。理解反例的关键是指出它否定了哪种推理，而不是记住其中的数值。

## 本书不试图覆盖什么

本书不是完整机器人学课程，不系统讲机械设计、ROS 工程、定位建图、强化学习算法大全或硬件选型；也不追求收录每个最新 VLA 和世界模型。读者可以把它看成连接视觉表征、世界预测、动作策略和系统证据的一座桥。

机器人操作与自动驾驶是两条并行案例。它们帮助展示同一概念在不同本体和风险等级下如何改变，而不表示两类系统可以直接共享动作、指标或安全结论。

## 给读者的阅读建议

第一次阅读不必进入实验目录，也不必理解维护状态页。先沿正文建立概念地图，在每章结束时尝试回答三个问题：本章新增了什么可观察证据，它允许作出什么新决策，还缺什么才能进入真实执行？

如果一个章节让你觉得边界过多，可以先抓住中心命题，再回看反例与证据说明。这些限制并非为了降低阅读兴趣，而是为了让“知道什么”和“尚不知道什么”同样清楚。
