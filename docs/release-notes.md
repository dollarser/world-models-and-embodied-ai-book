# v0.1.0-rc1 发布候选说明

> 冻结日期：2026-08-31
> 最近出版编辑：2026-09-02
> 发布形态：中文在线开源书候选
> 当前许可证：MIT

## 这个版本包含什么

- 七个部分、22 章中文正文；
- 面向计算机视觉背景读者的世界模型与具身智能学习路径；
- 遮挡条件下移动杯子和施工改道两个贯穿案例；
- 术语表、阅读地图、研究雷达和章节延伸阅读；
- 覆盖世界模型、RSSM、规划、想象学习、预测表征、空间表征、模仿学习、生成式动作、VLA、跨本体迁移、后训练、仿真、评测、实时性和安全边界；
- 章节练习、自检要点和用于解释协议的微型反例。

## 当前完成度

22 章已经完成结构、内容、术语、证据边界和教学审查。当前版本可以作为完整在线教材阅读，但仍处于 release candidate，而不是最终稳定版。

进入首个稳定版本前，重点工作是：

1. 分离读者正文与维护审计元数据；
2. 完成全书压缩和统一文字编辑；
3. 统一参考文献与引用格式；
4. 完成移动端、键盘和屏幕阅读器人工巡检；
5. 部署稳定在线站点并生成 PDF/EPUB；
6. 进行来自不同背景读者的试读。

## 已验证的范围

当前文档流程能够严格构建 22 章书站，并检查导航、内部链接、标题结构、公式、Mermaid 描述和折叠式自检内容。章节中的微型反例用于验证概念与协议，不代表相应大型模型或真实系统性能。

维护者可在[编写状态](status.md)查看细粒度声明、实验和资产状态。该页面不是普通读者的前置材料。

## 尚未验证的范围

本候选没有据此声称：

- 已复现 Dreamer、Diffusion Policy、VLA 或 learned simulator 的论文结果；
- 已验证 24 GB GPU 或双卡训练成本；
- 已在 MuJoCo、MetaDrive、CARLA、Isaac、ROS、真实机器人或车辆上完成整书实验；
- 已获得真实时延、可靠性、功能安全或道路部署证据；
- 所有快速变化的外部项目在未来版本仍保持相同接口。

这些限制不会阻止本书作为概念教材使用，但会限制任何性能、资源和部署结论。

## 面向读者的版本承诺

稳定正文优先维护定义、方法关系、反例和证据边界。模型版本、排行榜和快速变化案例优先进入[研究雷达](research-radar.md)，避免让热点更新破坏教材结构。

发现错误或希望贡献内容，请阅读[开放出版与勘误](open-book.md)和仓库贡献指南。
