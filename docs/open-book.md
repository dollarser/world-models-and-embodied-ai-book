# 开放出版、引用与勘误

本书以开放仓库维护，正文稳定结构与快速变化案例采用不同更新节奏。开放出版意味着读者可以检查来源、提交勘误并追踪版本，不意味着每次提交都构成新的正式版本。

## 版本层级

- `release candidate`：结构和主要内容完整，仍接受出版编辑与读者测试；
- `stable release`：具有冻结版本号、变更记录和可引用产物；
- `research radar update`：更新案例与来源，不自动改变稳定概念；
- `development state`：尚未进入正式发布说明的维护中内容。

引用时应尽量使用稳定 release；若引用当前候选，请同时注明版本和访问日期。HTML 在线版是内容与链接的规范版本，也是本书的唯一发布形态。具体口径与发布前检查见仓库 `maintenance/publication.md`。

## 如何引用

仓库根目录提供 `CITATION.cff`。建议引用格式为：

> dollars. 《世界模型与具身智能：从表征、预测到行动》. v0.1.0-rc1, 2026.

引用具体章节时，请增加章节标题和章节号。引用书中转述的论文结果时，应继续引用原始论文或官方资料，不能只引用本书代替一手来源。

## 内容许可与非商业边界

除另有注明外，本书原创正文、原创图表和原创表格采用 `CC BY-NC 4.0`。读者可以在署名、链接许可并标明修改的前提下，为非商业目的复制、分享、翻译和改编。商业出版、付费课程内容包、广告支持的内容再发布或其他主要谋求商业利益与金钱报酬的使用，需要另行取得作者授权。

仓库中的自有软件代码、脚本、测试、Schema 和程序化 fixture 继续采用 `MIT`。两种许可的完整范围见根目录 `LICENSE-CONTENT.md` 与 `LICENSE`。第三方材料不包含在本书授权中，其来源和许可优先于本书说明。

## 如何报告勘误

勘误应尽量包含：

- 章节、标题和原文位置；
- 问题属于事实、公式、术语、引用、排版还是理解歧义；
- 建议修改及其一手来源；
- 是否影响其他章节、图表或结论边界。

安全、许可和高后果建议的错误应明确标为高优先级。单纯偏好的措辞修改应说明它如何降低歧义或改善可读性。

## 哪些贡献最有价值

- 发现概念跳步、隐含前提或不成立的推断；
- 提供来自真实读者的卡点和误读反馈；
- 修正中英文术语、公式、坐标和时间语义；
- 更新已经漂移的官方来源，同时保留版本边界；
- 改善图表、导航、移动端阅读和无障碍体验；
- 提供不会把教学反例误写成模型成绩的说明。

具体提交要求见仓库根目录的 `CONTRIBUTING.md`。若希望提供真实阅读反馈，可直接使用仓库 `maintenance/reader-study.md` 中的反馈格式，不必替作者做全面审校。

## 内容更新原则

正文只吸收改变稳定定义、方法关系或证据边界的更新。新论文、新模型版本和排行榜变化优先进入研究雷达。案例进入正文前，应回答它补充了什么已有章节无法表达的概念，而不是只证明领域仍在快速发展。

所有第三方文本、图片、代码、数据和模型继续遵守原许可证。本书中的引用和链接不改变第三方资产的授权条件，也不表示作者有权对这些材料授予 `CC BY-NC 4.0`。

仓库源码中的 `CLAIM_META` HTML 注释用于把事实、推断、结果和建议绑定到维护清单。它们不会进入渲染后的读者正文，但在 GitHub raw 视图中仍然可见；这是可审计源码与清洁阅读页面之间的有意分层，不是需要读者学习的术语。
