# 全书终审：第1、5、7、22章与发布候选

> 审查日期：2026-08-31
> 审查基线：`68712f6` 之后的终审工作树
> 范围：第1、5、7、22章正文、四张实验卡、fixture/测试/结果、全书 manifest、导航、状态、流程与发布门禁
> 结论：四章达到 `reviewed`，全书 22 章均完成四类审查；GPU、大数据、真实仿真和硬件状态不变

## 1. 状态边界

本次把导论—生成基础—模型规划—综合项目闭合为全书最后一条教学链。没有运行模型训练、上游 checkpoint、MetaDrive/CARLA、机器人、车辆或 GPU；因此四个实验保持 `smoke`，第5、7、22章 GPU 状态保持 `pending`，第1章为 `not_required`。`reviewed` 表示正文和当前 S 档证据通过审查，不表示目标方法复现、实时性、安全性或道路部署。

## 2. 内容与教学审查

| 章节 | 内容结论 | 教学结论 |
| --- | --- | --- |
| 第1章 | 离线 CV 指标与闭环后果边界清楚，机器人/驾驶双案例不越权 | 明确无 3D/RL 前置，提供三条阅读路线和标量反例 |

自动驾驶不是附录：四章分别覆盖闭环误差、多未来、候选轨迹规划与 capstone 合同，并与第19章 MetaDrive/CARLA 分层、第20章指标和第21章最小风险网关一致。

## 3. 代码审查

四章共 29 个单元测试：第1章 6 个、第5章 7 个、第7章 7 个、第22章 9 个；全书共 136 个。`check_results.py` 逐章执行 smoke，并与实验卡登记的 22 个结果 JSON 做结构和值精确比较；实验卡只声明解析/手工 fixture 的结果。

终审修复两类输入合同，但固定指标未改变：

- 第5章 NLL/quantile 统一拒绝未归一化概率、非数值 support、非有限 target 和布尔 quantile；
- 第22章资源审计拒绝 NaN/Inf 显存，以及 GPU 数量与单卡显存互相矛盾的记录。

第1章对浮点安全边界使用显式容差；第7章 terminal value、状态、动作和 horizon 均有拒绝路径。没有把输入校验增强写成模型性能提升。

## 4. 一致性审查

- 22 章 document、EXP、CLAIM、FIG/TAB、依赖、资源档位和自动驾驶角色全部登记在 manifest；新增结果门禁发现并规范化第2/4/6/9章的历史结果结构，环境与限制只由实验卡记录，不再与 smoke 输出形成双重来源；
- 22 张实验卡均指向存在的结构化结果，正文只引用对应实验作用域内的数字；
- 第5章多模态分布进入第11章视频未来和第14章生成动作，第7章规划进入第17章 model exploitation，第22章复用第9/19/20/21章真实性与部署边界；
- 发布流程允许 `reviewed` 章节组成明确标注证据范围的在线候选，但不会把 `gpu_status: pending` 覆盖为 `reproducible`；
- 已移除第13、15章关于后续批次的过期正文描述，历史批次审查记录保留当时结论。

## 5. 发布候选门禁

```bash
make smoke-all
make check
make docs-build
git diff --check
```

门禁要求 22 章 Docker/CPU smoke、22 张实验卡严格 Schema、本地链接、manifest、MkDocs 导航和严格构建全部返回 0。Material for MkDocs 输出的 MkDocs 2.0 上游公告不属于本书文档 warning；构建本身必须无文档 warning。

## 6. 保留问题

- M/L1/L2 没有 GPU/数据/仿真/硬件实测，章节不能升级为 `reproducible`；
- S 档均为教学 fixture，不代表上游模型性能、样本效率、闭环安全或部署能力；
- 外部案例会漂移，需要按核查日期维护研究雷达；
- 2026-09-01 已补充回环静态服务器并打开严格编译产物的应用内浏览器面板；26 个 HTML、22 章页面和 877 个内部目标通过自动检查。真正上线仍需选定托管平台，并人工确认截图式多尺寸和可访问性视觉巡检。
