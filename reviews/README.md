- [批次 C：第3、10、11、12、19章四类交叉审查](batch-c-review.md)
- [批次 D：第8、16、17、18、20、21章四类交叉审查](batch-d-review.md)

`reviewed` 只表示正文和当前可执行路径通过内容、代码、一致性与教学审查，不自动表示 GPU、大数据或上游完整复现已经完成。
