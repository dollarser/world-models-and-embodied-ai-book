## 1. 教学与内容结论

本轮为第二部分增加 28 个与练习同编号的折叠式自检。答案采用“可核算最小闭环 + 开放设计边界”：数值题给出公式、输入、阈值和适用作用域；设计题给出最低合格字段、对照、分母与停止条件，不把一种参考方案写成唯一答案。

重点修正第9章原练习的隐含前提：当前 `EXP-09-01` 中非零动作幅度为 0.1，action-blind RMSE 为 `0.1√p`，不可能超过 action-faithful-biased 的固定 0.12。题目现要求先判断能否翻转；自检再推导一般阈值 `p*=(0.12/a)^2`。这避免读者为满足题面而伪造不存在的排名反转。

## 2. 公式与结果复核

- 第5章：三成员预测改为 `(-2,2,2)` 后，range 为 4、mean 为 `2/3`、对真值 -2 的绝对均值误差为 `8/3`，超过 fixture 的 0.25 defer 阈值；
- 第6章：固定轨迹上 `observation_gain=0/0.25/0.5/0.65/1` 的 filtering RMSE 分别约为 `0.0446/0.0451/0.0537/0.0608/0.0863`，open-loop RMSE 均约为 `0.3332`；free-nats 与 stop-gradient 解释和当前源码一致；
- 第7章：H=3 折扣路径与立即 harvest 的分界为 `(0.1+√0.41)/2≈0.3702`；五场景 risky outcome 的均值、最差 20% 与 chance constraint 临界点分别为 `x=-3/0.6/0`；
- 第8章：discount `[0.99,0.99,0]` 下 λ=0/0.5/1 的 start target 为 `0.396/0.639045/0.9801`；`[0.9,0.9,0]` 的累计 loss weight 为 `[1,0.9,0.81]`；
- 第9章：缺失 rollout 的 invalid-run、attempted-task failure 与 survivor-conditional 三种 estimand 分开，动作幅度—占比阈值没有越过当前 fixture 的证据边界。

## 3. 证据与资源边界

本轮只读取并复算仓库中的标准库 fixture 和已登记 smoke JSON，没有下载数据、模型或依赖，没有运行 GPU、神经网络训练、MetaDrive/CARLA、机器人或车辆。开放题示例中的驾驶阈值仅用于展示协议结构，不是道路安全标准或部署授权。
