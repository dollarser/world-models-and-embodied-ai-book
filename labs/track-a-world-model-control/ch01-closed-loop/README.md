# EXP-01-01：离线误差、反馈与闭环后果 smoke

两组五步 residual action 的逐步 MAE 都是 0.1；标量动力学积分后，持续同号序列越过 0.3 教学边界，交替序列没有。

第二个固定子实验在标量系统 `x[t+1] = x[t] + u[t] + d[t]` 上比较四种情况：无反馈、及时比例反馈、两步观测延迟，以及控制量不足。它报告状态、观测、原始/限幅动作、首次越界与饱和次数，用于说明反馈必须和时延、动作权限及边界语义一起审查。

```bash
make ch01-test-local
make ch01-smoke-local
make ch01-smoke
```

实验没有图像、学习模型、物理 controller、仿真或硬件。比例反馈只作用于无单位的手工标量系统；0.3 是严格大于才越界的教学阈值，不是机器人或车辆安全标准。代码和 fixture 按 MIT 许可发布。
