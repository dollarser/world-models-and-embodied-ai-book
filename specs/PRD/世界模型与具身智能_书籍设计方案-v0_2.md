# 《世界模型与具身智能：面向CV算法工程师的论文精读与复现》
## 书籍设计方案 v0.2

> 参考对标：《现代 AI Agent 架构：从原理到生产实践》(dollarser/modern-ai-agent-architecture) 的定位清晰度、六部分结构、内容边界与证据原则、开源仓库组织方式。

## 一、定位

**一句话定位**：一本面向计算机视觉算法工程师的开源技术书，以经典与前沿论文为章节骨架，带你从"能看懂图像"走到"能理解并复现让机器人/智能体感知世界、预测世界、在世界中行动"的核心方法。

**目标读者**：
- 有 CNN/Transformer 基础，做过分类/检测/分割/3D视觉，想转型做具身智能、机器人学习、自动驾驶世界模型、仿真基础设施的算法工程师；
- 不要求有机器人学、强化学习、物理仿真背景——这些作为"预备知识"在第一部分补齐；
- 不要求有扩散模型/VAE 基础——第5章提供从零到足够的生成模型速览。

**不是什么**：不是机器人操作系统(ROS)教程，不是机械/控制理论教材，不追求覆盖每一篇论文，而是选取真正决定这个领域脉络走向的节点性论文。

### 读者知识地图（放在前言，是本书最大差异化卖点）

| 你（CV背景）已经具备 | 本书要帮你补齐的 |
|---|---|
| CNN/ViT/Transformer 基础 | MDP/POMDP、序贯决策、on-policy vs off-policy |
| 目标检测/分割/深度估计 | VAE、扩散模型、流匹配的直觉（第5章速览） |
| 3D视觉：相机模型、点云、NeRF/3DGS | 用扩散模型做"动作生成"而非"图像生成"的思维转换 |
| 目标检测/分割/深度估计 | 机器人运动学/动力学、力控与阻抗控制的基本直觉 |
| 3D视觉：相机模型、点云、NeRF/3DGS | 把三维表征用于"可操作性/可供性"而非仅"可视化" |
| 静态数据集上的 train/eval | 闭环评测、sim2real gap、分布偏移在物理世界中被放大 |
| 单帧/离线推理 | 实时性约束（30-100Hz 控制频率）、安全边界、Approval/Sandbox 思维 |

> 第5章为没有生成模型背景的读者提供从零到足够的VAE/扩散模型/流匹配直觉，确保第11章（Diffusion Policy）和第15章（π0的flow matching）不会出现知识断层。

### 多路径学习地图

不同背景/目标的读者不必按顺序读完全书，参考 embodied-intelligence 的做法，给出四条建议路径：

| 路径 | 目标 | 建议章节顺序 |
|---|---|---|
| VLA / 机器人操作方向 | 想做机械臂抓取、双臂操作、通用操作策略 | 1→2→3→4→5→11→12→13→14→17→18 |
| 世界模型 / 仿真基础设施方向 | 想做自动驾驶世界模型、仿真数据生成、World Foundation Model | 1→2→5→6→7→8→9→16→17→20 |
| 自动驾驶感知决策方向 | 想把CV能力迁移到自动驾驶的世界模型/占据网络 | 1→4→5→8→9→16→17→20 |
| 快速上手路径（有硬件/想最快出demo） | 已有实体机器人/LeRobot硬件，想最快跑出第一个VLA demo | 1→3→4→5→11→13→18，直接跳到 LeRobot + SmolVLA/OpenVLA 部署 |

四条路径共享第1章（全景导论）和相应的预备知识章节，之后按各自重点展开，读完主路径后建议回头补齐其余章节作为拓展阅读。

## 三、章节详细设计

### 第一部分：地图与预备知识

**第1章 具身智能全景导论**
- 类型：综述型（非单篇论文精读）
- 核心议题：具身智能 vs 纯CV 的本质区别——闭环反馈、动作影响观测、部分可观测性(POMDP)、实时性约束、sim2real gap
- 锚点材料：Yann LeCun《A Path Towards Autonomous Machine Intelligence》(2022) 作为"为什么需要世界模型"的思想引子
- 产出：一张贯穿全书的"方法演化地图"（后续每部分都会在这张图上标注坐标）

**第2章 强化学习与序贯决策速成**
- 面向CV读者的 MDP/POMDP、value/policy、on-policy vs off-policy
- 锚点论文：PPO（Schulman et al., 2017）
- 复现：Gymnasium 经典控制环境（CartPole/Pendulum）上跑通 PPO，重点是建立"策略优化"的直觉而非工程调参

**第3章 机器人学基础工具箱**
- 工具型章节，非论文驱动
- 正逆运动学、简单动力学、PID 与阻抗控制的直觉
- 复现：一个 2R/3R 平面机械臂的正逆运动学推导 + 可视化

**第4章 物理仿真环境上手**
- 工具型章节
- MuJoCo vs Isaac Sim/Isaac Lab 对比：定位、生态、学习曲线
- 复现：搭建一个简单抓取任务仿真环境，跑通"观测-动作-奖励"闭环

**第5章 生成模型基础：从VAE到扩散模型与流匹配**
- 工具型章节，为后续世界模型（VAE编码观测，第6章）和VLA（Diffusion Policy，第11章；π0的flow matching，第15章）提供必要的生成模型直觉
- 不是"教你怎么写扩散模型代码"，而是建立"足够理解后续章节的直觉"
- 三个核心概念：
  1. **VAE**：编码器-解码器、隐空间、重参数化技巧（为第6章 World Models 的VAE编码做铺垫）
  2. **DDPM/扩散模型**：前向加噪-反向去噪、条件生成、Classifier-free guidance（为第11章 Diffusion Policy 做铺垫）
  3. **流匹配（Flow Matching）**：与扩散的关系、为什么π0用flow而非扩散（为第15章做铺垫）
- CV桥接："你熟悉的图像生成任务 → 这些生成机制如何被重新用于动作生成/世界建模"
- 复现：用 Hugging Face `diffusers` 库跑一个极简的条件扩散模型（如MNIST/CIFAR-10上的条件生成），5行核心代码展示"去噪过程"，建立直觉
- 与第11章的衔接：第11章开头只需一句话"扩散模型原理见第5章"，直接切入"动作分布的建模"

> **本部分复现原则**：全部使用免费、可在个人电脑/单卡上运行的环境，不要求读者拥有实体机器人或大规模GPU集群。

### 第二部分：世界模型——学习环境的内部表征

**第6章 世界模型开山之作**
- 论文：Ha & Schmidhuber, *World Models*（2018，arXiv:1803.10122）
- 方法：VAE 编码观测 + MDN-RNN 预测动态 + CMA-ES 进化策略
- 复现：简化版 CarRacing 环境上训练 VAE+RNN，在"想象"的隐空间中训练策略
- CV桥接：VAE 部分在第5章已建立直觉，新知识点是"在隐空间里做 rollout"

**第7章 隐空间规划：PlaNet**
- 论文：Hafner et al., *Learning Latent Dynamics for Planning from Pixels*（ICML 2019）
- 方法：RSSM（循环状态空间模型），基于模型的规划（CEM）
- 与上一章关系：从"学完模型再单独训策略"到"边学模型边规划"

**第8章 在想象中学习策略：Dreamer 系列**
- 论文：Dreamer（ICLR 2020）→ DreamerV2（Mastering Atari with Discrete World Models, 2021）→ DreamerV3（2023）
- 方法演进：连续隐变量→离散隐变量→跨领域统一超参数
- 复现：在 DeepMind Control Suite 的轻量任务上跑通 Dreamer 的核心 actor-critic-in-imagination 循环
- 延伸阅读补充：MuZero（Schrittwieser et al., 2019/2020）代表第三种哲学——不重建观测，只学习"对规划/价值估计有用"的隐动态（value-equivalent model）。建议在这里埋一个伏笔，与第9章的生成式路线、JEPA的非生成式路线形成三方对照，帮助读者建立"世界模型到底要不要重建观测"这条判断轴

**第9章 生成式 vs 非生成式：两条世界模型路线之争**
- 类型：对比分析型章节（呼应第15章VLA三方对比的写法），这是本书最重要的"路线之争"章节

**A. 生成式路线：视频生成即世界模型**
- 材料：Genie（Bruce et al., DeepMind, 2024）、Genie 2、**Genie 3**（DeepMind 博客，2025年8月，首个实时交互式通用世界模型，24fps，720p，可保持数分钟一致性）
- 定位：**案例分析型，非代码复现**——Genie 3 仍处于研究预览阶段，未开源、未发表完整论文
- 同技术路线的补充材料：GameNGen（Google，*Diffusion models are realtime game engines*，ICLR 2025，用扩散模型实时渲染DOOM）、Oasis（Decart/Etched，基于Transformer的Minecraft世界模型）——让读者看到"自回归隐动作学习"（Genie）与"扩散式实时生成"（GameNGen/Oasis）是生成式路线内部的两种实现方式
- 讨论重点：自回归视频生成 + 隐动作学习（无需标注动作数据）如何重新定义"世界模型"这个词的含义

**B. 非生成式路线：JEPA（Joint Embedding Predictive Architecture）**
- 论文脉络：I-JEPA（Assran et al., CVPR 2023）→ V-JEPA（Bardes et al., 2024）→ **V-JEPA 2**（Assran et al., Meta AI, 2025年6月）→ VL-JEPA / LeJEPA（2025）
- 核心主张（Yann LeCun）：像素级预测对"用于规划/识别的世界模型"而言是糟糕的目标，应该在隐空间/embedding空间做预测——这是对 Genie/Sora/Cosmos 这类生成式路线的正面挑战
- **关键实证锚点（用于章节对比表）**：V-JEPA 2-AC 仅用 62 小时无标注机器人观测视频学习后，在全新环境下 16 秒内完成"移动杯子"任务规划，成功率 80%；对比 Octo（15%）和基于 Cosmos 的方案（仅规划阶段就需 4 分钟）
- 内容边界提示：**这是一场正在进行中的路线之争，不是已有定论的技术优劣**。LeCun 本人已离开 Meta 创立 AMI Labs 专注这条路线，本章应如实转述"两派各自的论点和实证"，不替读者下结论
- 复现：I-JEPA 或轻量版 V-JEPA 的核心 masking + latent prediction 思路，在小规模图像/视频数据上跑通，与Genie隐动作学习的复现形成直接对比

**本章小结产出**：一张"生成式 vs 非生成式世界模型"对比表（训练目标、是否需要解码器、评测方式、适用场景、代表模型），作为全书方法演化地图的关键节点

**第10章 面向物理世界的世界基座模型**
- 材料：Wayve GAIA-1/GAIA-2（自动驾驶）、NVIDIA Cosmos（Physical AI World Foundation Model Platform）
- **补充案例1：Waymo World Model**（2026年2月，基于 Genie 3 打造，用于自动驾驶仿真训练）——作为 Genie 3 从"研究预览"走向"产业落地"的具体证据，与第9章形成呼应
- **补充案例2：World Labs Marble**（Fei-Fei Li 创立，2025年11月发布）——定位"空间智能"（spatial intelligence），联合创始人包括 **NeRF 论文作者 Ben Mildenhall**；输出为 3D Gaussian Splat + 碰撞网格，直接为下游物理引擎/机器人仿真准备。这是给CV背景读者的绝佳桥接案例，**建议与第17章（NeRF/3DGS）做双向交叉引用**：一个是"三维重建技术"，一个是"用同样的表征做世界模型"
- 讨论重点：世界模型从"游戏/玩具环境"走向"自动驾驶数据生成""机器人训练数据合成""三维空间生成"三条产业化路径
- 内容边界提示：Marble 是商业产品发布，其"遵守物理规律"等宣传表述需标注为 [技术报告/产品发布]，与经过同行评审的实证结果区分对待
- 案例分析 + 部分可复现的小规模视频预测模块

> **第二部分小结导读**：在 Part 6 会给出"如果你要往世界模型/仿真基础设施方向发展，接下来看什么"的路标。

### 第三部分：视觉-语言-动作模型（VLA）——让世界模型学会行动

**第11章 从模仿学习到动作生成**
- 基础：行为克隆(Behavior Cloning)的局限
- 论文：Diffusion Policy（Chi et al., RSS 2023）
- 复现：在 Push-T / 简单操作任务上训练 diffusion policy，重点体会"用扩散模型建模动作分布"与"用扩散模型生成图像"的异同
- 与第5章的衔接：扩散模型原理在第5章已建立，本章直接切入"动作分布的建模"

**第12章 端到端机器人 Transformer：RT-1**
- 论文：*RT-1: Robotics Transformer for Real-World Control at Scale*（Google, 2022）
- 复现：简化架构在仿真数据上训练，理解"把动作离散化为 token，用 Transformer 建模"的思路

**第13章 大模型加持的 VLA：RT-2 与 PaLM-E**
- 论文：*RT-2*（Google DeepMind, 2023）、*PaLM-E*（Google, 2023）
- 核心议题：网络规模预训练知识如何"迁移"到机器人控制；涌现的语义泛化能力
- 复现受限说明：原始规模不可复现，采用 OpenVLA（社区开源复现）作为可运行的替代练习对象

**第14章 低成本高精度操作：ACT / ALOHA**
- 论文：Zhao et al., *Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware*（2023）
- 方法：动作分块（Action Chunking）+ Transformer，解决高频控制下的复合误差问题
- 复现：ACT 核心模块在公开数据集/仿真双臂任务上训练

**第15章 通用具身基座模型三方对比**
- 材料：Physical Intelligence π0 / π0.5、NVIDIA GR00T N1 系列（N1 → N1.5 → N1.6/N1.7）、Google Gemini Robotics 1.5
- 架构对比维度：慢-快双系统（GR00T）vs 先语言推理再行动（Gemini Robotics）vs 扩散/flow 生成动作（π0）
- 案例分析 + 明确标注：三者均未完全开源，部分数据来自公司技术报告与第三方评测，本章使用 OpenPI（π0 社区复现）作为可运行练习
- **内容边界重点章节**：逐条标注每个"能力宣称"的来源类型（论文/技术报告/演示视频/第三方评测）
- 与第5章的呼应：π0 使用 flow matching 而非扩散模型做动作生成，读者在第5章已建立流匹配直觉，此处可直接理解架构选择

### 第四部分：三维表征与场景理解

**第16章 NeRF 与 3D Gaussian Splatting：给具身智能的三维先验**
- 论文：NeRF（Mildenhall et al., ECCV 2020）、3D Gaussian Splatting（Kerbl et al., SIGGRAPH 2023）
- CV桥接：这是你最熟悉的领域，重点讲清楚"渲染质量"之外，具身智能还关心什么（可查询性、实时性、可编辑性）
- 复现：3DGS 快速上手，讨论其在机器人建图/操作中的应用潜力
- **回指第10章**：NeRF 的作者 Ben Mildenhall 联合创立的 World Labs 正是用 3D Gaussian Splat 作为"世界模型"的输出格式（Marble）——本章讲的是三维重建技术本身，第10章讲的是这项技术如何被重新定位为"世界模型"，建议对照阅读，体会同一套表征在两种问题设定下的不同用法

**第17章 从感知到抓取：6D位姿估计与视觉-语言定位**
- 论文：FoundationPose（Wen et al., CVPR 2024）——模型-free/模型-based双模式，代表当前SOTA；或 Any6D（2025）作为更轻量的切入点
- CV桥接："你熟悉的特征匹配（SuperGlue/LoFTR）→ 如何扩展到SE(3)空间 → 如何用于抓取规划"
- 核心议题：CV中的"识别是什么" → 机器人中的"它在哪、怎么抓"——这是CV读者最具共鸣感的连接点
- 方法：从检测/分割到6D位姿估计（PnP/RANSAC、渲染-比较、神经隐式表征），再到视觉-语言定位（grounding for manipulation）
- 与第16章的关系：NeRF/3DGS重建的mesh可作为6D位姿估计的模型输入（FoundationPose的模型-based流程）
- 与第18章的关系：6D位姿估计的输出是affordance学习的重要输入条件
- 复现：在公开6D位姿数据集（YCB-Video/LINEMOD）上跑通一个简化版位姿估计+可视化
- 与VLA的衔接：明确说明6D位姿估计是传统pipeline的"硬编码感知"路径，而VLA（Part 3）是"端到端学习"路径——两者不是替代关系，而是工程选型问题

**第18章 从感知到可供性：occupancy 与 affordance 学习**
- 材料：自动驾驶 occupancy network、机器人 affordance 学习代表工作
- 核心议题：CV 中的"识别是什么"如何进化为具身智能中的"能对它做什么"
- 与第17章的衔接：affordance学习往往以6D位姿为输入条件，形成"感知→位姿→可供性→动作"的完整链条

### 第五部分：从仿真到现实的工程化

**第19章 Sim2Real 迁移**
- 论文：Domain Randomization（Tobin et al., 2017）
- 内容：域随机化、系统辨识、可微仿真（简介 Brax/Warp 思路）
- 复现：在一个简单任务上对比"无随机化"vs"域随机化"的迁移效果

**第20章 具身智能系统工程**
- 类比 Agent 书的"生产工程实践"部分
- 内容：数据闭环、评测基准（Habitat、RoboSuite、ManiSkill）、Policy/Approval/Sandbox 式的安全边界设计

## 四、统一章节写作模板（质量一致性的关键）

每个"论文精读型"章节固定包含以下小节：

1. **本章要解决的问题**——承接上一章，说明这篇论文补上了什么空白
2. **核心论文卡片**——标题、作者/机构、年份、发表渠道，并**明确标注来源类型**：同行评审论文 / 公司技术报告 / 研究博客公告（三者证据强度不同，必须让读者一眼看出）
3. **CV背景桥接**——"如果你熟悉 XX（你的CV知识），可以类比理解 YY（新概念）"，这是本书区别于通用教程的核心价值
4. **方法与关键公式**——只讲清楚最核心的 1–3 个公式/机制，配图，不做论文的逐段翻译
5. **与前序方法的关系**——放入全书的"方法演化地图"，避免孤立记忆
6. **代码复现**——开篇明确写"复现范围声明"（复现核心算法思想，还是完整训练流程；能否在个人电脑/单卡上跑）
7. **实验结果解读**——复现结果 vs 论文原始结果，如有差距，说明是算力/数据规模/工程细节导致，不夸大也不掩饰
8. **局限与开放问题**——自然引出下一章
9. **延伸阅读**——2–3篇相关论文，标注"本书未展开精读"

## 五、代码复现原则

- **目标是验证核心算法思想，不是复现 SOTA 指标**。这一点必须在每章开头写清楚，避免读者产生"跑不出论文效果=我做错了"的挫败感。
- 优先使用轻量、免费、可在单卡/CPU上运行的环境（Gymnasium、MuJoCo 自带任务、ManiSkill 轻量任务），不要求读者拥有实体机器人或大规模集群。
- 对于无法复现的超大规模/未开源模型（Genie 3、GR00T、π0/π0.5、RT-2、Gemini Robotics），**明确标注为"案例分析，非代码复现"**，并给出对应的社区开源复现项目作为替代练习入口。

| 原模型/方法 | 社区开源替代 | 说明 |

**各目录的设计取舍说明**（对比参考仓库后明确写下来，避免被误解为疏漏）：

- **`papers/` 只存元数据和笔记，不存论文PDF全文**：这是与 embodied-intelligence 的 `raw/`（直接归档23篇论文PDF）刻意不同的选择。部分会议论文/arXiv预印本的转载许可并不清晰，直接redistribute全文有版权风险；本书统一只存标题/作者/年份/来源类型/官方链接+本书自己的精读笔记，读者通过链接自行获取原文。
- **代码采用"正文内嵌关键片段 + `examples/` 存完整可运行版本"的折中方案**：embodied-intelligence 把代码直接嵌入章节 Markdown，阅读连贯性好但难以做CI测试；Agent书和 every-embodied 都用独立目录，可测试可维护但阅读时要跳出正文。本书采用折中：**正文中只保留讲解用的关键代码片段（10-30行，帮助理解算法核心逻辑），完整的可运行工程放在 `examples/`，正文用链接引用**，兼顾可读性与可维护性。
- **`examples/lerobot/` 作为VLA部分统一实验框架**：LeRobot 已成为社区事实标准（HuggingFace主推），集成 SmolVLA/ACT/Diffusion Policy，提供统一的数据格式、训练pipeline和评估工具。VLA章节（第11-15章）的复现建议基于 LeRobot 展开，避免每章重复配置环境。
- **`reviews/` 增加双轨维护机制**：
  - `status.md`：参考 every-embodied 给每章标注 ✅/🚧 的做法，维护全章节状态表（未开始/草稿/已复现验证/已定稿），标注"最后核实时间"。
  - `model-updates.md`：专门追踪 Part 2/3/6 涉及模型的版本变化（如 GR00T N1→N1.7 的迭代时间线、π0 系列更新、Genie 开源进展），与 `status.md` 区分——前者是"书稿完成度"，后者是"外部世界变化"。
