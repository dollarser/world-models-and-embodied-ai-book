# 《世界模型与具身智能》设计文档索引

## 当前基线

- [书籍设计方案 v0.6](./世界模型与具身智能_书籍设计方案-v0_6.md)：当前推荐方案。

v0.6 采用 7 部分、22 章、两条贯穿实验线、一条自动驾驶案例线和二维证据标注。
3D 视觉按零基础设计；必做训练不超过 24GB 单卡，少数选做实验最多使用 2×80GB。
研究基线核查日期为 2026-08-31。

后续章节模板、术语表、证据规则与实验卡 schema 应以 v0.6 为起点继续拆分，不再直接扩写旧版。

## 执行规范

- [书籍编写与审查执行流程](./书籍编写与审查执行流程.md)：规定 Specs 冻结、纵向样章、实验与正文协同开发、章节批次、资产追溯、四类审查门和发布流程。

当前开发设备无 GPU：近期只执行 Docker/CPU smoke、微型数据和文档检查；大型数据下载、GPU 训练与长时间实验均延后，并在完成目标硬件实测前标记为“待 GPU 验证”。

- [v0.5](./世界模型与具身智能_书籍设计方案-v0_5.md)：在 v0.4 稳定骨架上补充 2025–2026 研究、评测和开源教学生态复核。

- [v0.2](./世界模型与具身智能_书籍设计方案-v0_2.md)：补充生成模型前置、证据等级和 LeRobot 实验框架。
- [v0.1](./世界模型与具身智能_书籍设计方案-v0_1.md)：初始定位与 20 章结构。

## 版本规则

1. 已发布版本只做明显错别字修正，结构调整新建版本；
2. 每个版本写明资料核查截止日期；
3. 模型版本、产业进展和排行榜进入活页台账，不反复改写正文结构；
4. 关键设计决策在新版变更摘要中说明“改了什么、为什么改”；
5. PRD 文件统一命名为 `世界模型与具身智能_书籍设计方案-v0_N.md`，文件名不使用书名号、空格或小数点版本分隔符。
