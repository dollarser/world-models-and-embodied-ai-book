## 一、定位
**一句话定位**：一本面向计算机视觉算法工程师的开源技术书，以经典与前沿论文为章节骨架，带你从"能看懂图像"走到"能理解并复现让机器人/智能体感知世界、预测世界、在世界中行动"的核心方法。
**目标读者**：
- 有 CNN/Transformer 基础，做过分类/检测/分割/3D视觉，想转型做具身智能、机器人学习、自动驾驶世界模型、仿真基础设施的算法工程师；
- 不要求有机器人学、强化学习、物理仿真背景——这些作为"预备知识"在第一部分补齐；
- 不要求有扩散模型/VAE 基础——第5章提供从零到足够的生成模型速览。
**不是什么**：不是机器人操作系统(ROS)教程，不是机械/控制理论教材，不追求覆盖每一篇论文，而是选取真正决定这个领域脉络走向的节点性论文。
### 读者知识地图（放在前言，是本书最大差异化卖点）
| 你（CV背景）已经具备              | 本书要帮你补齐的                                             |
| --------------------------------- | ------------------------------------------------------------ |
| CNN/ViT/Transformer 基础          | MDP/POMDP、序贯决策、on-policy vs off-policy                 |
| 目标检测/分割/深度估计            | VAE、扩散模型、流匹配的直觉（第5章速览）                     |
| 3D视觉：相机模型、点云、NeRF/3DGS | 用扩散模型做"动作生成"而非"图像生成"的思维转换               |
| 目标检测/分割/深度估计            | 机器人运动学/动力学、力控与阻抗控制的基本直觉                |
| 3D视觉：相机模型、点云、NeRF/3DGS | 把三维表征用于"可操作性/可供性"而非仅"可视化"                |
| 静态数据集上的 train/eval         | 闭环评测、sim2real gap、分布偏移在物理世界中被放大           |
| 单帧/离线推理                     | 实时性约束（30-100Hz 控制频率）、安全边界、Approval/Sandbox 思维 |
| 模型训练经验（SFT/微调）          | "VLA后训练"：RL微调、经验回放、人类纠正信号（第16章）        |
> 第5章为没有生成模型背景的读者提供从零到足够的VAE/扩散模型/流匹配直觉；第2章为没有RL背景的读者补齐策略梯度与价值函数直觉——这两者是理解第16章（VLA后训练）的前置条件，学习路径中已体现。

- 论文脉络：
  - **π*0.6 + RECAP**（Physical Intelligence，arXiv:2511.14759，2025.11，🟢）：RL with Experience and Corrections via Advantage-conditioned Policies——通过自主经验、人类纠正、奖励反馈的迭代循环改进VLA，在装箱、做咖啡、叠衣服三个真实任务上验证；配套 SAC-N / IGDRS 等价值函数训练方法

  - **Human-to-Robot Transfer**（Physical Intelligence，2025.12，🟡）：人类视频数据对VLA的迁移价值
- CV桥接："你熟悉的 SFT→RLHF 大模型后训练流程 → VLA的 SFT（模仿学习）→ RL（经验后训练）几乎是同构的"——这是LLM背景和CV背景读者共同熟悉的连接点
- **WAM演进线索落点**：RT-2（直接出动作）→ VAM（先预测视频再出动作）→ WAM（世界模型+动作统一）→ **RL后训练用世界模型做模拟器**——世界模型与动作模型的融合趋势在本章收束
- 复现：在 LIBERO 或 LeRobot 内置仿真任务上，对 SmolVLA/OpenVLA 做一轮简化版 RL 后训练（可用开源 RIPT-VLA/PLD 实现），体会"RL让VLA超过其演示数据"的核心主张
- 复现范围声明：不追求论文的真实机器人结果，只复现"后训练带来成功率提升"的核心现象

## 四、统一章节写作模板（质量一致性的关键）
每个"论文精读型"章节固定包含以下小节（与v2一致）：
1. **本章要解决的问题**——承接上一章，说明这篇论文补上了什么空白
2. **核心论文卡片**——标题、作者/机构、年份、发表渠道，明确标注来源类型（🟢论文/🟡技术报告/产品博客，证据强度不同）
3. **CV背景桥接**——"如果你熟悉XX，可以类比理解YY"
4. **方法与关键公式**——只讲清楚最核心的1-3个公式/机制，配图
5. **与前序方法的关系**——放入全书的"方法演化地图"
6. **代码复现**——开篇明确写"复现范围声明"
7. **实验结果解读**——复现结果 vs 论文原始结果
8. **局限与开放问题**——自然引出下一章
9. **延伸阅读**——2-3篇相关论文，标注"本书未展开精读"
