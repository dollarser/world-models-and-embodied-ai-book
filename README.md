# 《世界模型与具身智能：从表征、预测到行动》

一本面向计算机视觉工程师、研究生和具身智能学习者的中文开源教材。

本书不按模型排行榜组织内容，也不把具身智能简化为若干可运行 Demo。它从一个更稳定的问题出发：观测怎样形成任务相关状态，预测怎样支持决策，动作怎样改变未来，系统又怎样在闭环、评测和部署中证明自己真正有效。

## 为什么写这本书

世界模型、VLA、生成式策略和具身智能发展很快，但许多资料存在三类断裂：视觉表征与控制决策断裂，论文方法与系统接口断裂，模型指标与真实闭环证据断裂。

本书用 22 章建立一条连续知识链：

1. 从视觉识别进入部分可观测的闭环系统；
2. 理解生成式世界模型、RSSM、规划与想象学习；
3. 建立可供行动使用的预测和空间表征；
4. 理解模仿学习、生成式动作和 VLA；
5. 分析世界模型怎样帮助策略，以及何时反而会被策略利用；
6. 把仿真、评测、实时性和安全边界纳入同一证据链；
7. 学会从问题、对照和证据出发判断一个具身智能系统。

## 这本书适合谁

- 熟悉 CNN、ViT、Transformer 或视觉任务，准备进入世界模型与具身智能的工程师；
- 希望建立完整概念框架，而不是只追踪最新模型名称的研究生；
- 已接触机器人、自动驾驶或 VLA，希望补齐评测与证据方法的读者；
- 需要组织课程、读书会或专题研究的教师与开源社区维护者。

不要求预先掌握强化学习、控制理论、机器人学或 3D 视觉。第 3 章会提供后文所需的最小机器人学与决策基础。

│   ├── part-01-loop/         第一部分：从视觉识别到闭环智能
│   ├── part-02-world-models/ 第二部分：学习一个可用于决策的世界
│   ├── part-03-representations/ 第三部分：可扩展的世界表征
│   ├── part-04-policies/     第四部分：从看懂世界到生成动作
│   ├── part-05-fusion/       第五部分：世界模型与策略融合
│   ├── part-06-systems/      第六部分：仿真、评测与部署
│   ├── part-07-capstone/     第七部分：可审计研究闭环
│   ├── javascripts/          书站交互增强脚本
│   └── stylesheets/          书站排版与视觉样式

## 本书的特点

- **概念优先**：模型名称服务于概念，不让版本更新破坏知识结构。
- **闭环视角**：始终追问动作如何改变下一次观测和状态分布。
- **反例驱动**：用最小反例揭示均值、相关性、覆盖率和成功率可能隐藏的问题。
- **证据分级**：区分论文事实、本书推导、教学反例、仿真结果与部署证据。
- **失败可解释**：保留模型利用、分布偏移、时延、失效和不可辨识边界。
- **机器人与自动驾驶并行**：用桌面操作和施工改道两个贯穿案例连接全书。
